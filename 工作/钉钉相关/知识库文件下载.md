# 钉钉知识库文件下载流程

> [!tip] 流程概览
> 获取知识库列表 → 获取知识库 → 获取节点列表 → 获取文件 DentryId → 获取下载信息

---

## Step 1 · 获取知识库列表

**所需权限：** 知识库读权限

```
GET /wiki/workspaces
```

[📖 查看接口文档](https://open.dingtalk.com/document/api/explore/explorer-page?api=wiki_2.0%23ListWorkspaces&devType=org)

---

## Step 2 · 获取知识库详情

**所需权限：** 知识库读权限

```
GET /wiki/workspaces/{workspaceId}
```

[📖 查看接口文档](https://open.dingtalk.com/document/api/explore/explorer-page?devType=org&api=wiki_2.0%23GetWorkspace)

---

## Step 3 · 获取节点列表

**所需权限：** 知识库节点读权限

```
GET /wiki/nodes
```

[📖 查看接口文档](https://open.dingtalk.com/document/api/explore/explorer-page?devType=org&api=wiki_2.0%23ListNodes)

---

## Step 4 · 获取文件 DentryId

**所需权限：** 知识库文档读权限

```
GET /doc/dentries/{dentryUuid}/queryDentryId
```

[📖 查看接口文档](https://open.dingtalk.com/document/api/explore/explorer-page?devType=org&api=doc_2.0%23GetDentryIdByUuid)

---

## Step 5 · 获取文件下载信息

**所需权限：** 企业存储文件下载信息读权限

```
POST /storage/spaces/{spaceId}/dentries/{dentryId}/downloadInfos/query
```

[📖 查看接口文档](https://open.dingtalk.com/document/api/explore/explorer-page?devType=org&api=storage_1.0%23GetFileDownloadInfo)

# 新荣记果实检测定制

本文档集记录新荣记果实检测定制的最终业务口径、当前实现、运行配置、异常处理和验收标准。遇到线上问题时，应先确认问题属于哪条链路，再进入对应专题。

> [!important]
> 文档中的“最终口径”代表已经确认的需求；“当前实现”代表截至 2026-08-13 的代码行为；“已知风险”代表尚未消除或需要再次确认的事项。三者不能混用。

## 业务目标

将果实检测平台产生的 AI 巡检结果每小时同步到巡店系统，完成媒体转存和 ClickHouse 入库；发现违规时向对应负责人发送小时提醒；每周自动汇总问题、生成巡店报告及整改，并发送按组织权限计算的个性化周报；同时提供小时、周 H5 看板用于查询和下钻。

## 全链路

```text
果实检测 API
  → 每小时拉取结果
  → 同步策略字典
  → 图片/视频转存巡店 OSS
  → Kafka
  → Kafka Connect
  → ClickHouse
  ├─ 小时违规提醒 → 飞书 → 小时巡检汇总 H5
  └─ 每周汇总
       ├─ 自动提交巡店报告 → 标准整改流程 → App 相关链接
       └─ 飞书周报 → 每周巡检汇总 H5 → 小时明细下钻
```

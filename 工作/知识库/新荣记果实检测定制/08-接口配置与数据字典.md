# 接口、配置与数据字典

## Shoteyes 接口速查

| 方法 | 路径 | 用途 | 鉴权 |
| --- | --- | --- | --- |
| POST | `/api/xinrongji/fruitInspection/process` | 手动执行小时同步 | 需要 |
| POST | `/api/xinrongji/fruitInspectionNotice/weekly` | 手动执行真实周任务 | 需要 |
| POST | `/api/xinrongji/fruitInspectionDashboard/context` | 解析身份、返回组织树和策略 | ignore auth，业务内鉴权 |
| POST | `/api/xinrongji/fruitInspectionDashboard/hourly` | 查询小时看板 | ignore auth，业务内鉴权 |
| POST | `/api/xinrongji/fruitInspectionDashboard/weekly` | 查询周看板 | ignore auth，业务内鉴权 |
| POST | `/api/xinrongjiFruitStrategy/list` | 查询已同步策略 | 正常业务鉴权 |
| GET | `/api/feishu/jsApiSign` | Main Server 生成飞书 H5 JSAPI 签名 | 按 Main Server 规则 |
| POST | `/api/tenant/settings` | 保存通知角色配置 | 需要系统设置权限 |

context、hourly、weekly 对外免 HMAC/登录中间件不等于无权限：Server 必须通过 `userId` 或飞书授权码解析用户，再按该用户组织权限过滤数据。底层 ClickHouse Rider action 不对外开放。

## 外部果实接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/open/inspection/results` | 分页获取检测结果和策略字段 |

不再使用 `/api/v1/open/tenant-strategies`。

## 看板请求字段

context：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `userId` | 二选一 | App 传巡店用户 `_id`，优先使用 |
| `feishuAuthCode` | 二选一 | 飞书一次性授权码 |

小时、周查询：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `userId` | 是 | context 解析出的巡店用户 ID |
| `dateFrom` | 是 | 上海时区开始时间 |
| `dateTo` | 是 | 上海时区结束时间 |
| `keyword` | 否 | 门店或问题搜索 |
| `strategyCodes` | 否 | 多个策略代码，空表示全部 |
| `storeIds` | 否 | 多个分区或门店 ID，空表示全部授权门店 |

## 环境变量

| 变量 | 必填 | 默认/用途 |
| --- | --- | --- |
| `FRUITEVO_API_KEY` | 是 | 果实 API Key，由部署 Secret 注入 |
| `FRUITEVO_API_BASE_URL` | 否 | 默认 `https://almond.fruitevo.cn` |
| `FRUITEVO_RISK_DASHBOARD_URL` | 否 | H5 看板基础地址 |
| `FRUITEVO_FEISHU_NOTICE_APP_ID` | 生产通知需要 | 果实专用飞书应用 ID |
| `FRUITEVO_FEISHU_NOTICE_APP_SECRET` | 生产通知需要 | 果实专用飞书应用 Secret |
| `KAFKA_HOSTS` | 是 | Kafka Broker 列表 |
| `IMAGE_BUCKET` | 按环境 | 生产 `shoteyes`，非生产 `shoteyes-dev` |
| `ENVIRONMENT` | 是 | 决定 OSS 环境前缀等行为 |

Secret 的真实值不得写入 Git、Obsidian、日志、报错文本或前端响应。

## Tenant Setting

| Key | 值格式 | 用途 |
| --- | --- | --- |
| `fruitInspectionSyncCursor` | 带时区 ISO 字符串 | 小时同步成功水位 |
| `fruitInspectionHourlyNoticeRoles` | JSON 角色 ID 数组 | 小时提醒角色 |
| `fruitInspectionWeeklyNoticeRoles` | JSON 角色 ID 数组 | 周报角色 |

周任务还复用租户现有整改时长、承诺时间等设置，但不新增“已通知用户”状态。

## 检测结果字段

果实结果整体作为 Kafka 单条消息保存。主要字段如下：

| 字段 | 说明 | 入库处理 |
| --- | --- | --- |
| `resultId` | 检测结果唯一 ID | Kafka key，ClickHouse 去重键 |
| `fieldId` | 果实侧场所 ID | 原样保留 |
| `fieldName` | 果实侧门店名称 | 与巡店 `store.name` 精确匹配 |
| `type` | 问题类型 | 原样保留，用于明细和聚合 |
| `category` | 问题分类 | 原样保留 |
| `severity` | 严重级别 | 只参与违规判定，不展示等级 |
| `detectTime` | 检测时间 | 转为 `YYYY-MM-DD HH:mm:ss.SSS` |
| `status` | 结果状态 | 原样保留 |
| `images` | 图片 URL 数组 | 替换为 OSS Key 数组 |
| `videoUrl` | 视频 URL | 替换为 OSS Key |
| `confidence` | 置信度 | 原样保留 |
| `description` | 问题描述 | 原样保留，用于明细和搜索 |
| `isCompliant` | 是否合规 | 参与违规判定 |
| `taskId` | 果实任务 ID | 原样保留 |
| `deviceId` | 摄像头/设备 ID | 原样保留 |
| `deviceName` | 摄像头/设备名称 | 原样保留 |
| `aiPriority` | AI 优先级 | 原样保留 |
| `aiReason` | AI 判断原因 | 原样保留 |
| `strategyId` | 果实原始策略 ID | 原样保留 |
| `tenantStrategyId` | 历史租户策略 ID | 原样入库，不用于模板匹配 |
| `tenantStrategyName` | 租户策略名称 | 策略展示和搜索 |
| `strategyName` | 策略名称 | 策略展示和搜索 |
| `strategyCode` | 策略代码 | 模板匹配、筛选、周聚合主键 |

## Mongo 策略字段

`XinrongjiFruitStrategy` 只保存策略选择所需信息：

```text
strategyCode
strategyName
tenantStrategyName
通用有效性和审计字段
```
